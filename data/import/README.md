# Imports

Drop CSV exports from other tools here to add them to the AI chart, for example
Semrush AI Visibility or Position Tracking prompts, or any rank tracker that checks AI answers.

Columns (header row required):

| column | example |
|---|---|
| run_date | 2026-11-17 |
| platform | ChatGPT (Semrush) |
| prompt | best reporting tool for agencies |
| in_answer | yes / no / no answer |
| organic_pos | 3 (optional) |

Rename the export's columns to these before you upload. The next build picks the file up.
